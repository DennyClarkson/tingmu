# 听幕

本地播放器与语言学习伴侣，Python + Qt Quick。默认普通话学粤语，繁体原句、分词粤拼、简体讲解；也支持同语言学习。

**0.12.0** 在「准备 → 新任务流程」可选经典流程或字幕 Agent。字幕 Agent 检查外挂和内嵌文本字幕，可以直接采用学习语言原文和已对齐的译文。仅有译文时，仍识别原声音轨，并将时间匹配的译文用于复核与讲解。每种情况都需要逐句讲解。队列显示选用的字幕、处理步骤和检查详情。界面语言在「视图 → 界面语言 / Language」切换，提供简体中文、繁體中文与 English。[操作说明](docs/portable.md)

准备视频时，听幕按工作区的语言生成原文字幕、逐句讲解和已知语言译稿。0.10.0 可在「工作区设置 → 文本模型与 API」或队列设置中调整并发量，默认 4 路，可选 1–16 路。单句校验失败时会保留已经通过的字幕，并向模型指出需要修正的字段。暂停后可以从检查点继续。[使用说明](docs/portable.md)

## 用对话创建学习工作区

在「对话」中说「我要学英语了」。听幕会创建或复用对应工作区，检查电脑实际可用的 CPU、显卡、内存和共享模型目录，再推荐语音模型。已有模型直接使用。新模型会显示预计下载量，点「同意下载」或在原对话输入这四个字即可授权本次下载。

可以明确指定任意学习组合，例如「帮我创建一个叫『北欧语伴』的工作区，用斯瓦希里语学冰岛语」。两端都接受语言代码，也可选择同一种语言。内置识别模型覆盖不同语种，其他语种可使用配套字幕或相应的转写服务。

将视频放进工作区的 `media/` 文件夹，听幕会等待复制完成并自动准备字幕。工作区可以沿用本机文本服务；使用之前配置的远程讲解与对话服务时，界面会列出用途、模型及服务主机供确认。[便携版使用说明](docs/portable.md)

## 工作区、语音与逐句修订

打开听幕会回到上次使用的学习工作区。点主界面顶部的工作区名和语言组合，可以切换工作区、新建工作区或打开「工作区设置」。每个工作区分别保存媒体库、字幕和讲解、收藏与笔记、对话、队列和播放进度。0.11.0 的文本模型连接和任务分配由同一安装中的所有工作区共享。「观看」「准备」「学习」是在同一工作区内切换任务视图。

在主界面字幕行点「纠正」，或在学习伴侣、全屏伴侣点「纠正此句」。写下你听到的字词或确认的意思，点「复核并保存」。内置 Agent 根据这条说明修订选中的字幕，并更新整句的译文、分词和讲解。成功后，工作区 `documents/` 内同名的 SRT 字幕和 JSON 学习材料同步更新，原始识别和声学时间仍可追溯。单独导入的源字幕保留在原位置。

需要生成字幕时，默认先在本地减弱配乐，再识别所选音轨。便携版配有 Spleeter 人声分离和 pyannote 说话人切换检测模型。本地分句结合可用的词级对齐；多人同时说话、唱歌或极短插话仍可能误分或漏分。有角色标注的字幕和带说话人时间段的外部服务可直接提供额外信息。

「工作区设置 → 语音识别」提供内置模型、本机 API 和远程转写。没有独显可用 Whisper small 配合 CPU，也可连接已有的本地或远程语音服务。内置模型可以下载，也可选择共享缓存里已有的 CTranslate2 Whisper 模型目录。语音 API 可查询服务端模型或手填 ID；远程发送音轨需单独开启。接口须支持带时间段的 `verbose_json` 或 `diarized_json`。[语音 API 配置](docs/external-asr.md)

「工作区设置 → 文本模型与 API」可停用文本模型、仅用本机 API 或允许远程 API。打开连接管理，填写本机 Ollama、LM Studio 或其他兼容服务的地址，可为复核、讲解和学习对话分别选模型。所有工作区共用当前安装的 `.cache/` 模型库，同一个权重只需下载一次。

## 团队从这里开始

本仓库保存应用源码、测试、构建脚本、设计文档和随包开源字体。运行环境、语音模型、便携 EXE、视频及个人学习资料单独保存在本机，不随 Git 上传。

Windows 10/11 x64，开发使用 Python 3.12 和 uv。在已安装 Git、uv 的 PowerShell 中：

```powershell
git clone https://github.com/DennyClarkson/tingmu.git
cd tingmu
powershell -NoProfile -File scripts/setup.ps1 -CpuOnly -Dev
.venv\Scripts\python.exe -m tingmu gui
```

这会按 `uv.lock` 安装 CPU 开发环境，不下载语音模型。首次打开、阅读代码和运行自动测试无需 API Key；实际识别需另备 FFmpeg 与语音模型，云端讲解/对话需在软件内配置自己的模型连接。不要把凭据或个人数据放进提交。

## 0.5 新增与完善

- **准备 → 处理队列**：勾选一个或多个视频，清除当前识别与讲解，或仅重做讲解；确认框可选择重新排队。全量重做强制重新识别，不误用同名旧字幕。视频、收藏、笔记、聊天和观看进度保留，旧材料恢复副本在 `data/material-backups/`。
- **学习**：收藏先进入收集箱，明确整理后才写入按语言、主题组织的 Markdown 笔记；原收藏保留并标记“已整理”。笔记支持母语对比、用法、例句、学习目标和个人备注，手写内容保留，保存有版本冲突保护与备份。来源可回到视频原句，也可按视频筛选。间隔复习提供回忆、揭示答案及掌握程度反馈，学习伴侣可据此出题。
- **对话**：多会话、Markdown 标题/列表/表格/引用、代码块与复制、流式回复、停止、编辑和重试。编辑/重试保留原会话另建分支，沿用当时的视频、语种、模型和思考强度；部分回复与应用操作记录持续保存。
- **Agent 操作**：处理所选视频、明确要求时重新生成、管理队列、控制播放、切换工作区与已有模型、整理收藏、修改并保存笔记和备注。修改既有笔记前读取全文、检查版本；软件实际执行成功后才确认。讲解偏好立即保存并用于后续生成，已有资料不会自动重跑。
- **思考强度**：聊天中直接选择默认、关闭、最低、低、中、高、更高；显式选择会传给模型，服务商不支持时明确报错。支持的选项随模型而异。
- **思考与进度**：DeepSeek 等模型返回的公开思考与最终回答分开显示，可折叠、复制，并随会话保存。GPT 可在模型管理中选择 Responses 接口请求思考摘要；服务未返回摘要时，仍显示连接、思考、工具和生成阶段，不编造内容。旧连接不自动切换协议。
- **模型管理**可从「文件 → 全局文本模型」、对话或队列设置打开。选择 OpenAI、DeepSeek、通义千问、Gemini、Anthropic、Ollama 或自定义端点，保存连接后可加载模型列表，也可填写模型 ID。在「任务分配」页为复核、讲解和对话分别选择连接。
- **主题与字体**：森林、纸页、雾青、石墨四套主题，菜单、下拉框、浮动窗口即时跟随。随包提供思源黑体、思源宋体、Source Sans 3 与 Source Code Pro，并附开源许可。
- **暂停选词**时，主界面和全屏伴侣用颜色和文字标出「已收藏」和「已整理」。遇到已整理的词，点一次查看提示，再点同一词卡即可重新加入待整理收藏。单词本保留每次收藏的不同原句，可分别跳回视频。同一句反复点击只保留一个出处。也可选中字幕原文收藏，或收藏整句。
- **交互修复**：点击全屏后空格仍为暂停；浮动模块释放主窗位置；伴侣区分未打开、无字幕、处理及字幕空档；长笔记键盘编辑跟随光标，滚轮阅读不跳回。

手工密钥使用 Windows DPAPI 加密，普通设置/日志/导出不保存明文；换电脑或 Windows 账号后需要重新输入。密钥字段保存后清空，不提供明文回显。模型列表来自服务商，列出不代表账号一定有调用权限。[模型与安全说明](docs/providers.md) · [新界面说明](docs/ui-v5.md)

## 启动

拿到完整便携包后，双击 **Tingmu.exe**（本机构建输出位于 `dist/Tingmu/`）。便携包包含运行环境，可选本地语音模型与 GPU 依赖会显著增加体积；请整体保留或移动，无需 CMD 或另装 Python。**源码克隆不含便携包**，开发启动见上方步骤，打包见 [便携版说明](docs/portable.md)。

默认工作区保存在 EXE 旁的 **data/**。自建工作区位于 **data/workspaces/工作区名/**，源码运行时对应 **.data/workspaces/工作区名/**。模型、临时文件及 QML 缓存在当前安装的 **.cache/**。视频可引用原位置，也可通过媒体库复制到工作区，生成的资料和导出文件均保存在项目内。API 密钥可从环境变量读取或用 Windows DPAPI 加密保存到所属工作区。

## 准备视频

1. 在媒体库点 **文件** 多选任意位置的视频，或点 **文件夹** 扫描目录。可以分次添加不同文件夹，也可拖入文件。
2. 在 **学习伴侣齿轮** 选择已知语言、学习语言和程度。在 **处理队列齿轮** 设置本地识别、处理音轨、复核和讲解模型；音轨按自己的视频选择。
3. 勾选视频，点 **加入处理队列**；切换顶部 **准备**，点 **开始队列**。每个视频依次进行本地识别、Astra文本复核和学习讲解。可暂停、继续、重试失败项，重开仍保留进度。
4. 已有同名字幕优先使用，也可通过文件菜单导入 SRT/ASS/SSA/VTT。请使用自己有权处理的视频和字幕；本仓库不分发验收样片或已生成的个人学习资料。

## 观看与学习

**观看**布局默认显示媒体库、视频、学习伴侣和滚动字幕。点击字幕定位，点词语收藏，给整句写笔记。伴侣中的**收藏**支持跳回视频、删除、CSV/Markdown导出及Astra/Sol复盘。**来源**显示原始文字、复核说明及时间依据。

顶部 **对话** 打开独立聊天窗口，可追问当前句、练习语言或让 Agent 操作应用。聊天底部选择模型与思考强度，点击“模型”管理连接，点击“讲解偏好”保存学习要求。

各模块的设置位于其右上角齿轮。拖动分隔线调整大小；拖动标题到其他模块交换位置，拖出工作区或点箭头浮动，关闭浮动窗口会放回。观看与准备的模块位置分别保存。工作区菜单可打开模块或恢复默认布局。

## 字幕与全屏

**不合并相邻短句**。前一条结束到后一条开始的空隙不超过设定值时，把前一条保持到后一条开始，直接切换；默认500ms，可在字幕模块齿轮调整0–1500ms。长空隙正常清空，前后跳转立即计算当前字幕。

强模型复核将长原句断为短字幕，单条最多42显示列（约21个全角汉字），严格验证分段连接后仍等于正文。原始记录、文字和声学时间保留；按文本长度估算的拆分时间在来源中明确标记。本机长片验收的898条原始记录对应1015条显示字幕，这是测试结果，不是随仓库提供的数据。原识别的短时段仍可能切换很快，填空隙不会伪造新的声学对齐。

**F**或双击视频全屏，**Esc**退出。伴侣浮层尺寸固定，内容内部滚动；拖动标题移动、拖动**右下角**缩放。播放器齿轮可设置浮层透明度、字号及内容。全屏和浮动使用同一播放器；暂停时切换窗口也保留画面。

支持音轨、内嵌字幕、外部字幕、字幕延迟、倍速、音量、静音、画面适应方式、A/B循环、重听、上下句/视频和PNG截图。空格暂停，左右跳5秒，上下切句，M静音；输入文字时不触发播放快捷键。

## 模型与边界

复核和对话默认模型 ID 为 **gpt-6-astra**，批量讲解为 **gpt-5.4-mini**；它们来自本机已验证连接，新成员应按自己服务商的权限选择或填写模型，不能假定默认 ID 在每个账号可用。所有文本任务可选择自配模型，队列也可使用本地分词。关闭云端文本会阻止模型网络请求。粤语支持另行安装的 **Qwen3-ASR 1.7B + ForcedAligner**，另有 Whisper turbo。文本复核保留原稿和声学时间；教学提示词强调语境、重点表达与易混点，不能二次改写已复核正文。

文本模型没有听音，不能保证人名、漏字和语气词完全准确。拆分句的释义与讲解仍来自完整源句。外部ASS/SSA当前仅播放文本，不重现复杂特效；图片字幕无OCR。ASR中断需重新识别当前视频，复核与讲解按检查点继续。

已实际验证Windows窗口的视频画面、全屏浮层、右下角缩放、独立聊天和暂停时切换；也验证了文件夹搬迁、本地GPU识别、多个视频批处理及主流格式解码。详细证据见reports和handoff。

## 开发者模式与日志

在 **帮助 → 开发者模式** 开启，再点 **查看日志**。可查看运行环境、模型配置、媒体和队列状态；日志支持级别筛选、搜索、跟随最新记录及详情。**导出诊断**写入本APP的 `data/diagnostics/`，**日志文件夹**打开 `data/logs/`。

正常模式记录启动、处理阶段、耗时和异常类型/堆栈位置；开发者模式增加DEBUG操作事件。结构化 `events.jsonl` 每份2MiB、最多4份；启动/运行输出 `application.log` 每份2MiB、最多3份。日志自动轮换，不写字幕正文、对话、笔记或API请求/响应正文，密钥会脱敏。源码调试使用项目 `.data/logs/`。

## 开发

前端入口 `src/tingmu/quick/main.py`，界面在 `quick/qml/`，Python桥在 `quick/bridge.py`。旧 `ui/app.py` 只保留为历史回归参考，不参与默认启动。源码默认数据在本仓库 `.data/`，不再默认写C盘用户目录。

环境准备、验证和日常流程见 [docs/development.md](docs/development.md) 和 [CONTRIBUTING.md](CONTRIBUTING.md)。构建入口 `scripts/build_portable.ps1`；刷新界面复用已有运行时，不重新下载模型。原生可视验收脚本 `scripts/verify_quick_ui.py` 仅操作自己的测试窗口，须指定隔离数据目录。

先读 [skill.md](skill.md)、[handoff.md](handoff.md) 与 [contracts.md](docs/contracts.md)。子代理只允许原生工具调用 GPT-6.2-Astra，禁止使用已弃用的dispatching-parallel-agents skill。
