# 听幕 Tingmu

**简体中文** · [English](README.en.md)

听幕是一款 Windows 视频播放器，可以把一集剧或一段课程做成逐句学习材料。播放时点字幕就能回听原句、查看讲解、收藏词句，也可以让学习伴侣结合当前对白答疑。默认用普通话学粤语，支持自行选择已知语言与学习语言，包括同语学习。

## 开始使用

**Windows x64 便携版**　在[最新正式版](https://github.com/DennyClarkson/tingmu/releases/latest)的 **Assets** 中下载文件名以 `-windows-x64-portable.zip` 结尾的压缩包，完整解压到可写目录，双击 `Tingmu/Tingmu.exe`。首次启动会离线检测本机组件。点「暂不下载，直接进入」，即可用 **0 B 下载**播放视频和使用外挂字幕。需要转写时，再到「运行环境与依赖管理」配置所需组件。[所有版本](https://github.com/DennyClarkson/tingmu/releases) · [便携版与首次设置](docs/portable.md)

点顶部工作区名称，选择你熟悉的语言和视频里要学的语言。简体中文、繁體中文和 English 可在「视图 → 界面语言 / Language」随时切换。界面语言整份安装共用，字幕和讲解使用工作区的语言组合。

**从源码运行**　`main` 分支包含最新开发改动，便携版功能以对应版本的发布说明为准。在 Windows 上安装 Git 和 uv，克隆仓库后进入含 `pyproject.toml` 的目录。在 PowerShell 执行下面的命令即可启动 CPU 开发环境。首次安装需要下载依赖，语音模型按需配置。[开发环境与检查](docs/development.md)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -Dev -CpuOnly
.\.venv\Scripts\python.exe -m tingmu gui
```

## 准备字幕和讲解（0.12）

1. 在媒体库添加视频，打开要学习的那一集，再到「准备」选择音轨和「新任务流程」。默认的**经典流程**沿用工作区已有的识别、复核和讲解设置。**字幕 Agent** 适合手头已有字幕，或想让听幕检查视频内嵌字幕的情况。流程在任务入队时确定。
2. 有指定字幕时，选择「字幕 Agent → 为当前视频选字幕并入队…」。支持 SRT、ASS、SSA 和 VTT。要自动检查同名或匹配的外挂与内嵌字幕，直接在媒体库勾选视频并加入处理队列。
3. 点「开始队列」。字幕 Agent 会检查字幕内容、可辨认的剧集信息、所选音轨和时间覆盖。展开任务可查看采纳和排除的来源、采用了多少句原文和译文，以及正在执行的步骤。

以**用中文学英语**为例，字幕 Agent 按以下方式处理通过检查的材料。

| 可以采用的字幕 | 英语原文从哪里来 | 中文译文怎么处理 |
| --- | --- | --- |
| 仅英语原文 | 直接采用原句和时间轴，跳过转录 | 生成并核验译文 |
| 英中双语 | 直接采用原句和时间轴，跳过转录 | 保留逐句对齐的译文，只为缺译的句子生成并核验 |
| 仅中文译文 | 转录所选英语音轨，或复用匹配的原声转录 | 用时间重叠的中文作复核与讲解参考，依据英语原文生成并核验译文 |
| 无可用文本字幕 | 转录所选音轨，或复用匹配的原声转录 | 根据原文生成并核验译文 |

内嵌文本字幕适用同一判断。DVD、PGS 等图像字幕会在任务中列出，目前需要 OCR 才能读取字句。**字幕 Agent 每种路径都需要逐句讲解**，双语字幕也一样。缺少可用讲解模型时，任务保留已取得的材料。配置模型后可点「重试失败」继续。[操作与进度说明](docs/portable.md)

## 观看、学习与数据

- 在「观看」点击字幕跳到对应时间，按上下键切句，按 F 进入全屏。可在「来源」核对原始文字和时间依据，发现听写有误时用「纠正」提交复核。
- 收藏词语或整句后，可从学习笔记跳回对应视频原句。独立的「对话」窗口能解释当前句、安排视频处理、整理收藏，支持多会话、停止、编辑与重试。[对话与应用操作](docs/conversation.md)
- 在「文件 → 全局文本模型」为复核、讲解和对话分配连接。各工作区单独控制文本权限。语音识别默认在本机执行，使用外部转写服务还需授权发送所选音轨。[文本模型与权限](docs/providers.md) · [语音接口](docs/external-asr.md)
- 视频可引用原位置，也可主动复制进工作区。便携版将学习资料放在程序旁的 `data/`，源码运行默认放在 `.data/`。仓库提供源码、测试和打包脚本，模型、便携运行环境和个人学习资料另行准备。[目录与空间](docs/disk-space.md)
