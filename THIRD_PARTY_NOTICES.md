## 按需安装 · Optional downloads

独立媒体工具、推理引擎、CUDA 环境和模型权重均在解压后另行配置。用户在运行环境管理中复用本机工具或安装所需库，在工作区的模型管理中选择权重，同一安装内的工作区共用模型缓存。听幕以独立子进程调用 FFmpeg/ffprobe。Qwen 也在隔离的 `runtime/asr/` Python 子进程中运行，soynlp 属于该可选环境。Windows 安装器使用 `app/tingmu/assets/runtime-deps/windows-cp312-x64.json` 指定的构件与 SHA-256。源码开发依赖在 `pyproject.toml` 和 `uv.lock`，完整的 Qwen 开发环境另见 `scripts/qwen-requirements.lock.txt`。

After extracting the clean ZIP, users can reuse local tools or install the optional libraries through runtime management. Workspace model management downloads the selected weights into an installation-wide cache. Tingmu invokes the standalone FFmpeg/ffprobe tools as subprocesses. Qwen runs in a separate `runtime/asr/` Python process, and only that optional environment installs soynlp. The Windows installer pins its artifacts and hashes in the manifest below. The Python project lock and the larger Qwen development lock also include dependencies outside the portable payload.
