# 验收记录

仓库只保留已审阅的汇总结果，不上传个人学习数据、原始字幕、模型请求/回答正文或机器诊断转储。

| 文件 | 内容 |
| --- | --- |
| [acceptance-v5.json](acceptance-v5.json) | v0.5 自动回归、真实界面交互、DeepSeek/GPT 调用及数据保留检查 |
| [portable-v5-validation.json](portable-v5-validation.json) | 正式便携包的构建、媒体与原有资料保留检查 |
| [v5-reasoning-live.json](v5-reasoning-live.json) | 公开思考/摘要的文本接口实测计数及服务返回模型名 |

这些结果记录的是指定开发环境中的历史验收，不能代替当前提交的 CI，也不代表所有模型、账号、设备或语种均通过测试。当前提交的自动检查见仓库 Actions。

旧版报告仍留在原开发机，本次建仓不删除。`handoff.md` 和历史设计文档中指向旧报告、`.cache/` 或便携数据的路径是本机取证位置，克隆源码不会包含它们。新增报告默认忽略；确需共享时先移除密钥、个人路径与内容，再单独审阅并加入允许列表。
