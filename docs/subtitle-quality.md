# 字幕质量与便携版实机复验

验证使用同一测试片的隔离副本。原实测目录的字幕、审计与日志以只读方式检查。实验只向工作区授权的文本服务发送字幕证据。所有音频识别、对齐和分离在本机执行。

## 355 秒实跑

## 全片固定证据与前处理对照

原审计含 86 块、8,035 个对齐单元，其中 2,055 个零时长，85 块含坍缩。旧文档 950 条，已发布 SRT 1,069 条，其中 62 条 ≤100 ms，最短 15 ms。用相同的文本和原始对齐重放新声学规则，9,525 个字符及全部对齐单元逐项守恒，得到 907 条声学原句。继续执行本地门禁得到 904 条，零新增重叠，其中 27 条 ≤100 ms、128 条 <500 ms、37 条单字。全片数字来自固定证据重放；新一轮 GPU 识别和线上文本模型覆盖上列三个片段。

以至少 10 个词法字符且不足 200 ms 为极端压缩口径，旧稿有 6 条。门禁可在前方可用区间内回推起点，并在真实静音、已占用字幕区间或换人处停止。旧稿重放后还剩 1 条。原先 32 字挤入 80 ms 的报价行脱离该区间。声学修复后再过门禁，1972.160 秒处仍有一条 10 字、133 ms 的问句，两侧紧接其他对白，标记为不确定并计入 `unresolved_timing_count`。

在三个片段中的 11 个完整窗口，固定 ASR 原文、模型和设备重新对齐。原音轨、Spleeter、频谱抑制各有 917 个单位，零时长分别为 208、216、215 个。2400 秒窗口的 99 个单位分别有 20、30、30 个零时长。该对照支持以原音轨提供对齐证据；无法从中断定粤语高频辅音损失是坍缩的唯一原因。

## 各来源的边界

- Qwen 在窗口尾部选择持续静音或平滑能量谷。对齐和换人使用原音轨。坍缩估算使用邻近可信边界，保留原始字词、原始时间和修复依据。
- Whisper 所有内置型号和本地 CTranslate2 目录共用带词时间戳的 worker。关闭 VAD 时，静音证据与模型置信度、重复证据共同决定是否抑制幻觉。100 秒 CUDA large-v3-turbo 实测，原无词戳 7.421 秒，带词戳和 Silero 为 9.547 秒、337 个词；同一快照走本地目录、关闭 VAD 为 4.063 秒、365 个词。速度受解码回退和预热影响，其他型号由离线分支测试覆盖。
- 本机和远程语音 API 共用有界 PCM 切窗、上传许可和时间段校验。音频切窗参考原混音，服务端时间与分块偏移保存为证据。测试使用回环服务器及合成响应验证发送内容、微重叠、长句和跨块碎片。只有带时间依据的响应可进入字幕流程。
- 文件和内嵌文本轨在学习导入时提取对白、识别双语轨道并保护已有译文。普通播放可使用原字幕。语种、版式或并行人物不足以确立译文配对时采用保守处理。确认过的双语句只请求讲解。
- 所有新建学习材料及将送入文本模型的旧材料，共用来源感知规整器。它折叠滚动字幕、按局部时间、长短和标点保守缝合碎片，按标点安全拆分长句，规整微重叠并标识估算。原始证据和每个输出 ID 的来源在 `pre_llm_lineage`，仅 `pre_llm_audit` 的计数进入诊断日志。已收藏、手工修订和已有译文的 ID 受保护。
- 复核、讲解与核验各自对门禁产出的固定 ID 集工作。播放及双语 SRT 共用可读显示时间。若间隙允许则延长驻留。比例分片任一部分小于 600 ms 时保留整句。

## 模型分句的输入与回退

工作区、队列齿轮和 CLI 均可显式选择 `llm_regroup`。新任务默认 `local`。队列冻结模式，缓存同时核对视频、来源、区间、模式和模型规格。已有配对译文、手工修订、收藏及笔记引用受保护。跨模式重组会保留派生 ID 所在的来源关系，已经保存的学习资料可以继续补齐。

智能模式按时长和输入预算分块，提供局部连续索引、原字词、声学起止时间及停顿线索。推断换人属于软提示，明确说话者和显著长静音可构成硬边界。模型输出引用区间。客户端逐字符检查所有输入有序完整覆盖，并验证改字幅度、数字、字符边界与时长。无词戳的粗段可按源段内部的字符范围拆分，比例估算会写入 `timing_basis`。无效返回经过有界重试和拆块后按局部证据回退。已验证的输出直接进入教学。取消后可以按输入和模型指纹恢复。

首次在报价段做直接重组时，换人估计落在一个字内部，曾使“阿姨”和“三千九”再次断裂。改为软提示后，最终三段实跑的 966 个原始对齐索引都能回溯。缓存切换及笔记保护集成修复后，再次经生产入口逐字段对照 208、621、97 个单元，与实际发起重组请求时的输入一致。回归矩阵覆盖 Qwen 与 Whisper 词戳、本机与外部 API 段、人工双语和滚动字幕，也覆盖日、韩、泰、阿、法、英及无空格汉字文本、伪造时间、遗漏输入和中断续跑。
