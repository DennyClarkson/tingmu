# 听幕 v4 界面

Qt Quick 原生工作区保留同一个 QMediaPlayer、模块浮动与固定尺寸全屏伴侣。新增学习视图，聊天保持独立窗口。

## 主题与字体

`Theme.qml` 是每个 QML 引擎共享的 singleton，直接绑定 `backend.settings.theme`。森林、纸页、薄雾、石墨使用语义化背景、边框、文本、强调色；主窗、浮动模块、模型管理、日志和全屏伴侣即时更新。视频黑底与字幕白字是媒体显示的固定语义。图标由本地 SVG 字符串按主题着色，不依赖 GPU shader 或网络。

字体放在 `quick/qml/fonts/`，主入口负责注册。Source Han Sans SC 为中文界面，Source Han Serif SC 为阅读标题，Source Sans 3 为英文模型/读音标记，Source Code Pro 为代码与时间。四家族来自 Adobe 官方仓库，随附各自 OFL 许可和 `SOURCES.txt`；运行时不下载字体，不依赖微软雅黑或 Consolas。常规字重由字体提供，其余字重由 Qt 合成。

`AppMenu`、`Choice`、`AppDialog` 统一菜单、下拉框和确认框。Choice 箭头使用 Canvas，避开字体符号缺字。方向键操作菜单和下拉框时，播放器快捷键暂停接管，Esc 关闭菜单。

## 学习工作区

顶部观看 / 准备 / 学习切换不重建播放器。语言导航、中央 Markdown 笔记、右侧收藏来源三栏；主题和视频筛选针对来源列表，全文笔记标题明确保持不变。窄桌面下侧栏固定较小宽度，正文保留可用阅读区。

笔记支持安全预览、Markdown 编辑、修订号保护保存、AI 整理、打开文件与导出。未保存草稿按语言及修订号保存在工作区偏好（quick-layout.json），编辑停顿 600 ms 后自动落盘，主窗关闭前立即刷新当前草稿。外部语言切换不会串写；返回语言或重新启动应用后可恢复草稿。保存显式带编辑语言。打开或导出时若有草稿，说明使用已保存版本。正式 Markdown 保存成功或明确放弃修改后，删除对应语言草稿；恢复草稿继续使用原修订号进行冲突保护。草稿只包含笔记内容与修订号，不保存密钥。

复习卡显示问题、展开答案、回到原句，以及再学一次 / 有点难 / 记住了 / 很熟悉四档评分。来源使用 `tingmu://entry/<id>`，由 bridge 验证并定位视频。正文预览只消费 bridge 提供的安全 blocks，原始 Markdown 始终用于编辑保存。

## 对话与模型

聊天支持新建、切换、改名、删除会话，模型选择和独立模型管理窗口。快捷建议将当前句、收藏练习与复盘送入输入框。正文渲染标题、表格、引用和列表，代码独立分块并原样复制；所有链接交给 `openLink` 验证。Markdown 的段落、表格和链接颜色由 `formatMarkdown` 格式化，组件拥有零延迟单次 Timer，销毁后不遗留异步排版回调。

回复中显示状态、停止生成，完成后可重试或编辑用户消息。用户上翻时记录阅读位置，流式 model 刷新后恢复；回到最新按钮重新启用自动跟随。新建会话和滚动恢复已有真实 QML 测试。

模型管理使用服务预设、名称、API 地址、环境变量 / 本机保护密钥 / 无凭据三种来源。密钥输入框是 Password，保存或关窗即清空，从未回填已有密钥。可先不填模型名称保存连接，再加载模型列表或手填；同一服务可复制为新连接。讲解、复核、对话各自分配连接。折叠的高级选项可设置最大输出 Token 数及推理强度。界面解释跨电脑需重输密钥，本地 Ollama 预设可免密钥。

## 队列与观看

队列多选后可清除识别、复核和讲解，或只重做讲解。确认框明确保留视频、收藏和个人笔记，可选择清除后重新排队；运行中不允许重置。已清除或暂停任务有重新排队入口。

主伴侣与暂停的全屏伴侣允许选中文字收藏、点击词语、收藏整句、进入学习工作区。播放时全屏隐藏交互操作，固定窗口尺寸、标题拖动、右下角 resize 与内容内部滚动保持原行为。

## 验证

`tests/test_qml_workspace.py` 原有五项与 `tests/test_qml_v4.py` 新增八项真实 QML 交互测试通过：独立窗口主题、笔记保存和复习、空模型 ID 保存、暂停全屏选词、不变浮层尺寸、会话创建、流式阅读位置、跨语言及重启草稿、菜单和下拉框键盘。所有测试使用隔离数据；QML warnings 为零。

`.cache/v4-ui/` 保存隔离合成内容截图：1280×720 观看与学习、920×740 聊天、460×640 小聊天，以及可滚动模型表单。截图属于视觉验证，不代表已经在用户现有媒体或模型服务上完成质量验证。另有 `.cache/v4-native-ui/` 的 Windows 原生隔离实例截图，已目视验证按钮文字不截断、图标和小聊天布局；静置 1 秒 CPU 时间增量为 0.0 秒，没有排版回调循环。真实视频与便携 EXE 验收由根代理整合。
