# 磁盘与数据目录

把源码和便携包放在空间充足的磁盘。依赖、GPU 运行时及语音模型远大于源码；完整本地识别环境通常需要额外数 GiB，具体取决于选用的模型和设备。

## 开发目录

以下路径均相对于项目根目录，默认不进入 Git：

| 路径 | 内容 |
| --- | --- |
| `.venv/` | 主程序及开发依赖 |
| `.cache/qwen-venv/` | 独立 Qwen 运行环境 |
| `.cache/qwen-models/`、`.cache/models/` | Qwen / Whisper 权重 |
| `.cache/uv/`、`.cache/uv-qwen/`、`.cache/pip/` | 安装下载缓存 |
| `.cache/python/` | 安装脚本下载的 Python |
| `.cache/huggingface/`、`.cache/torch/`、`.cache/cuda/` | 模型 SDK / GPU 缓存 |
| `.cache/tmp/`、`.cache/qml/`、`.cache/qt-shaders/` | 临时文件和界面缓存 |
| `.data/` | 设置、字幕文档、收藏、笔记、聊天与观看进度 |
| `dist/Tingmu/` | 本机构建的完整便携包 |

`scripts/setup.ps1`、启动器和程序初始化只为当前进程设置缓存路径，不修改其他软件的用户/系统环境变量。安装前可用 `scripts/setup.ps1 -CpuOnly -Dev -Check` 查看计划。详见 [开发入门](development.md)。

## 便携目录

完整便携包中的 `data/` 是学习资料，`.cache/` 包含语音模型及缓存，`runtime/` 是运行环境。保留完整文件夹，不能只移动 EXE。视频通常留在原路径，数据按视频路径与语种关联；移动视频与移动软件是两件不同的操作。

旧版本可能在 `%LOCALAPPDATA%\Tingmu` 留有个人学习数据。它不是下载缓存，不能随清缓存操作删除。导入旧资料是单独步骤，先备份并核对来源/目标，不能通过安装自动替换。

## 清理原则

- 先确认目录用途、大小和是否仍由环境引用。优先使用工具自己的缓存管理命令，避免跨软件批量删除。
- `.data/`、便携 `data/`、笔记备份和素材不是缓存。不要为了释放空间删除它们。
- `.venv/` 和 `.cache/qwen-venv/` 是可用运行环境；删除后需要重新安装。虚拟环境还可能引用项目外的基础 Python，不能只凭路径位置判断可删。
- 模型权重可以重新下载，但删除后会影响离线识别；发布包使用的权重和开发缓存可能各有一份。
- 如使用目录链接，大小统计可能重复计算目标；删除链接并不会释放目标数据占用的空间。

早期开发机的缓存迁移清单和磁盘清理记录保留在本机忽略目录，不属于团队安装步骤；不要照搬他人机器的删除命令。
