# 原生工作区 v2

听幕采用 PySide6 原生菜单和可停靠面板。标题栏可以拖动、浮动为独立窗口，面板可以合并成标签；`布局` 菜单重新打开隐藏的面板。

- **播放器**：画面、学习字幕、定位、倍速、音量、播放状态。音轨、内嵌字幕及字幕延迟在设置面板；A–B 循环、截图和画面比例在播放或文件菜单。
- **学习伴侣**：当前原句、随宽度重排的分词与读音、讲解、收藏与笔记。对话使用独立面板，不占用伴侣标签。
- **字幕列表**：搜索原文、译文、原始识别文本或读音；单击定位对应的原始声音时间。当前阅读组自动高亮。
- **媒体库与处理队列**：媒体库支持多选；队列可以加入所选或整个目录，顺序准备、暂停、继续、重试失败项和移除所选。队列使用当前设置的快照并持久保存；完成后刷新正在看的媒体，不切换影片。

默认学习布局为播放器在左、学习伴侣及独立对话在中、字幕列表在右。影院布局只保留播放器；两种预设均可继续调整。`保存布局` 与正常退出保存停靠、标签、浮动、窗口几何信息到当前数据目录 `workspace.json`，启动恢复；`重置布局` 回到学习预设。媒体库和队列默认收起，可从菜单打开。

## 全屏与阅读

`F` 或画面双击进入独立无边框全屏窗口，只有视频部件被移入，菜单和停靠面板留在工作区；独立紧凑控制条提供播放 / 暂停、进度定位、时间与退出全屏。`Esc`、`F` 或再次双击退出；播放器、音轨和播放位置沿用同一个实例。全屏时隐藏并在退出时恢复原先浮动的工作区面板。控制条在播放空闲 3 秒后自动隐藏，移动鼠标重新出现；暂停时保持可见，拖动定位过程中不隐藏。

全屏学习浮层显示原句、读音和译文，可拖动位置；设置支持显示开关、不透明度、字号及可选讲解；讲解开关随布局保存。关闭浮层且控制条隐藏后，全屏仅剩视频。浮层与伴侣使用相同的阅读时间轴。

阅读选项包含最短字幕展示、短停顿衔接和伴侣保留时间。展示分组与延长时间由 `SubtitleTimeline` 计算，文档中的源字幕、原始识别文本和时间戳不改写；上一句、下一句、循环和收藏使用稳定的展示组 ID。字幕导出仍使用文档源句及原始时间轴。字幕保留与伴侣保留分开，短停顿中原句学习内容不会反复清空；任意定位直接计算当前内容，不累积延迟任务。

来源标签使用“机器转写 / 外部字幕 / Astra 文本复核”等中性状态。工具提示保留原始文本、模型、对齐警告与低置信度信息；“Astra 文本复核”指模型基于文本复核，不表示人工听音确认。学习菜单可请求当前已有字幕的强模型复核；模型、云端文本开关和批量准备配置仍相互独立。
