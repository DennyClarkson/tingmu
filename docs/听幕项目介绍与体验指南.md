# 听幕 Tingmu｜用视频学粤语和英语

听幕是一款 Windows 桌面语言学习应用。学习者听视频原声，遇到没听懂的一句，可以定位并重听，对照原文、中文译文和词句讲解，再把想记住的表达收藏起来。例如，选择「用普通话学粤语」后，听到的是粤语原声，看到的是粤语字幕，读到的是用简体中文写的解释。接入文本模型后，还可以围绕正在播放的这一句向学习伴侣追问。

## 灵感来源

听幕的学习设计，即源于日常刷剧时本人的需求和感受，受到两项外语词汇研究的印证。一项关注观看视频时用什么语言解释生词，另一项关注复习时先回忆还是直接重看答案。

Lee 与 Choi（2024）让 101 名韩国大学生观看带关键词字幕的视频。与只看关键词或阅读目标语释义的学习者相比，阅读母语释义的学习者在随后的词形回忆测验中表现更好。这项发现为听幕采用普通话释义提供了依据。学习者听粤语或英语原声时，可以在当前字幕旁读到熟悉语言的解释，再带着对词义的理解重听原句。[Lee 与 Choi 的字幕释义研究](https://doi.org/10.1080/09588221.2024.2412103)

Huang 等人（2025）让 108 名中英双语者使用数字词卡学习斯瓦希里语与中文词对。在 30 分钟后的测验中，练习时先尝试回忆答案的学习者，在提示回忆任务中的表现优于直接重看词对的学习者。听幕据此设计了复习卡。学习者先看收藏的原句，试着回想表达的含义和用法，再揭示译文核对，必要时返回原声重听。[Huang 等人的数字词卡研究](https://doi.org/10.3390/bs15111540)

## 评委如何开始体验

1. 将 `Tingmu-Demo.zip` 完整解压到 Windows 电脑上，进入解压后的 `Tingmu-Demo` 文件夹，双击 `Tingmu.exe`。
2. 点击「开始用普通话学粤语」或「开始用普通话学英语」，再点首页的「继续学习」。从出现方向选择页到播放，**只需两次点击**。两个工作区都已备好视频、字幕和逐句讲解，可直接离线体验。
3. 在「观看」中点选一句字幕，听一遍原声，再看「当前句」里的译文和讲解。点击「收藏整句」，切到「学习 → 我的收藏」，就能找到刚才那一句。「学习」里还可以写笔记、做间隔复习。下次打开时选择同一方向，点击「继续学习」即可回到保存的播放位置。

## 普通版如何使用

**先看内置视频。** 全新安装首次打开时，在「选择字幕处理方式」点「跳过，稍后设置」。选好学习方向，进入「视频源」，在对应视频旁点「下载并准备」。程序会从本机 `127.0.0.1` 的视频源将随包视频导入当前工作区，载入已做好的学习材料并播放。这条路径无需外网、API 密钥或本地语音模型。当前测试版每次启动都会显示学习方向选择页。

**学习自己的视频。** 点击首页「本地视频」选择文件，也可以直接把文件拖入首页，再点「一键准备」。程序会复用可用字幕和已完成的步骤，按工作区设置进行语音识别、分句和讲解，完成后打开学习页。需要从原声生成字幕时，可选择「下载语音模型本地处理」，也可以选择「使用 API 密钥」，跟随向导填写转写服务地址、语音模型和密钥，并授权该工作区发送音轨。新生成的 AI 讲解需要另行配置文本模型。

## 如何用 DeepSeek 体验学习伴侣

内置材料已经包含逐句讲解。想让伴侣回答自己的问题，可以单独配置 DeepSeek 文本连接。

1. 点击窗口顶部的工作区名称，选择「工作区设置 → 文本模型与 API → 管理全局连接与任务分配…」。
2. 在「服务预设」选择 DeepSeek，填入密钥和该账户可用的模型 ID，点击「保存连接」。进入「任务分配」，将「学习对话」分配给刚保存的连接。
3. 在当前工作区选择「允许远程文本 API」并确认。回到「观看」，暂停在有字幕的一句，打开「对话」。可以试着问：“这句话里哪个词最口语？请用普通话解释，再给我一个日常例句。”

DeepSeek 文本连接用于讲解和问答。需要把新视频的音轨转成字幕时，在「工作区设置 → 语音识别」配置本地模型或支持带时间戳字幕的转写服务。音轨和文本分别授权，各服务按账户规则计费。
