# 听幕 v0.5 界面行为与验证

本版把观看、收藏和整理笔记的边界说清楚，并修复全屏键盘与浮动窗口的实际交互问题。播放器继续使用同一个 QMediaPlayer，原有字幕时间轴、浮层拖动和右下角缩放行为保留。

## 观看与全屏

学习伴侣不再一律提示“打开视频并准备学习材料”。没有当前字幕时，界面区分四种情况：

- **尚未打开视频**：提示打开视频开始观看。
- **视频已打开，但没有学习字幕**：提示导入字幕或进入准备工作区生成材料。
- **当前视频正在处理**：说明正在准备学习材料，完成后显示逐句内容。
- **已有字幕，但播放位置处于空档**：说明这里没有当前字幕，下一句出现时自动更新。

点击全屏按钮后，焦点会交给播放器。按空格发送播放／暂停操作，并保持全屏；Esc 退出全屏。输入框、编辑框及下拉框保留各自的键盘操作。

播放快捷键同时检查 bridge 提供的 `focusWindow`，只在实际获得键盘焦点的播放器窗口生效。这样，独立聊天窗口中的方向键不会被后台主窗用来切换字幕；聊天输入框中的空格也不会控制播放。

暂停时，可在全屏伴侣中拖选原文，再点击“收藏选中文字”；也可以点击词语或“收藏整句”。原文控件提供“当前字幕原文”的 Accessible 名称和选择说明。选区在点击收藏时保持，避免按钮获得焦点后丢失选中文字。浮层仍为固定尺寸，内容在内部滚动，只有用户拖动右下角才改变尺寸。

## 浮动工作区

模块浮动后，主窗中的原布局位置会隐藏，不再保留“模块已浮动”的占位卡。相邻模块使用释放出的空间；一整列没有停靠模块时，该列也会让出宽度。

通过浮窗的放回按钮或工作区菜单，可以恢复停靠。恢复复用原模块实例，不重建播放器或切换 QMediaPlayer。模块交换与布局保存继续沿用现有工作区机制。

## 对话与讲解偏好

聊天界面增加思考强度选择：默认、关闭、最低、低、中、高、更高。默认表示沿用模型连接设置；其他选项分别对应 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`。选择保存在共享设置中，停靠与浮动聊天显示相同状态。模型和服务支持的选项可能不同，不支持时应由请求错误明确说明，界面不擅自替换选择。

“讲解偏好”入口可编辑学习目标、母语背景、重点难点和例句要求。保存后用于后续讲解及学习对话，不自动重新处理已有材料。学习工作区、聊天和伴侣设置均可进入这个编辑器；伴侣通过受限工具更新偏好后，界面也读取同一份设置。

聊天显示工具操作的进行中、成功或失败状态，以及安全的结果摘要。一次操作的开始与结束事件合并显示，完成后不会同时留下“进行中”。历史回复失败时，可看到保存的具体错误信息。

模型实际返回思考内容时，每条回复增加默认折叠的“思考过程”或“思考摘要”。进行中显示实时秒数和状态；展开后最多占用 220 像素高度，长内容在内部滚动。内容按纯文本显示，可选择和复制；流式更新保留展开状态，停止后和历史会话中仍可阅读已返回部分。没有返回内容就不展示思考区，也不生成替代文字。连接、思考、工具执行、生成回复分别显示阶段提示，停止提示优先。

模型管理中，OpenAI 与自定义兼容连接可明确选择 Chat Completions 或 Responses（思考摘要）。已有连接不会自动切换；其他服务预设不提供 Responses 选项。实际是否支持该接口、是否返回思考内容由模型和服务决定。

点击“停止”后，当前会话的标题和正在生成的回复会立即显示“正在停止…等待当前连接结束”，按钮变为不可重复点击的“停止中”。连接可能仍需要时间返回；输入、新发送和新对话在请求结束前保持禁用，已有部分回复保留。结束后显示“已停止生成”并恢复输入；切换到其他会话不会沿用这个停止提示。

受限工具可以请求打开观看、准备或学习工作区，以及相应模块。界面收到有效工作区动作后切换并显示目标窗口；进入准备或学习时会退出遮挡它们的全屏播放器。

## 收藏、笔记与复习

学习工作区分为三个明确入口：

- **收藏**：观看中收集的词句先进入收集箱。可搜索、按视频或主题筛选，并查看全部、未整理或已整理条目。每条收藏可以添加个人备注，记录联想、母语对比、疑问或自己的例句。
- **笔记**：用户明确点击整理后，收藏才进入学习笔记。可以整理所选条目，或整理尚未整理的收藏，并补充本次整理要求。原收藏继续保留，并标为已整理。笔记可以包含语言对比、用法、例句、容易混淆的地方和个人练习目标；具体内容由保存的笔记决定。
- **复习**：展开复习卡答案、返回视频原句，并使用再学一次、有点难、记住了、很熟悉四档评分。

笔记支持按条阅读和整本 Markdown 阅读、编辑。单条预览只去掉与外围标题完全匹配的首个标题，原始 Markdown 和编辑内容不变。整本笔记始终可用；自由手写内容不必先成为目录中的独立条目。

收藏备注使用条目修订号保存；备注本身不会把收藏标为已整理，也不会自动写入笔记正文。整本笔记继续使用修订冲突保护，未保存草稿按语言保存到工作区偏好，支持重启后恢复。来源链接仍交给后端验证并定位视频。

编辑长笔记时，Ctrl+Home、Ctrl+End 以及键盘输入或粘贴会让滚动区域跟随插入点。使用鼠标滚轮阅读时保持用户的阅读位置，不会自动跳回光标；继续键盘编辑时再显示插入点。

## 字体、主题与窗口尺寸

森林、纸页、薄雾、石墨四主题继续共用语义颜色，主窗与浮动窗口实时更新。字体继续随包提供 Source Han Sans SC、Source Han Serif SC、Source Sans 3、Source Code Pro 及各自开源许可，运行时不下载网络字体，也不依赖微软雅黑或 Consolas。

小窗口下，笔记会收起额外的来源侧栏，为正文保留空间；聊天模型和思考强度选择允许收缩。聊天正文的 QML 字体、QTextDocument 默认字体和普通正文片段字重已实际读取确认均为 **400 Normal**。

恢复旧工作区时，聊天面板的最小高度按实际占据的位置分配，避免交换到播放器等位置后沿用过低的高度。较高窗口为聊天保留至少 420 像素；较矮窗口同时为相邻面板保留空间。短聊天面板收紧间距和输入框高度、隐藏快捷建议，保留会话、发送、模型、思考强度以及至少 48 像素的回复区域。独立聊天与历史会话继续可用。

## QML 验收证据与边界

本轮合并执行以下三个测试文件，共 **25 项测试通过**，Ruff 检查通过，测试记录中的 QML 引擎警告为空：

- `tests/test_qml_workspace.py`
- `tests/test_qml_v4.py`
- `tests/test_qml_v5.py`

这些测试实例化真实 QML 和桥接对象，并使用隔离数据。新增回归覆盖：四类伴侣空态；实际鼠标点击全屏后按空格与 Esc；输入框空格；跨浮窗下拉框方向键；浮动模块释放空间并恢复同一实例；共享思考强度和偏好保存；收藏与 Markdown 分离；显式整理命令；整理状态过滤；备注修订保存；工作区动作与工具状态。既有回归继续检查主题、菜单、队列、聊天滚动、笔记草稿和固定浮层等行为。

全屏选词回归使用 TextEdit 字符位置计算鼠标坐标，再执行真实 QTest 按下、拖动、释放和收藏按钮点击，最后检查存储中的原文精确为“我哋”。这项测试发现并验证了点击按钮时选区丢失的修复，不仅是程序直接设置选区。

长笔记回归使用 180 行合成内容，实际点击正文、Ctrl+End、粘贴、Ctrl+Home 和滚轮阅读，检查插入点可见且手动阅读不被抢回。停止回归在 380 像素宽的独立聊天窗口实际点击按钮，检查即时等待提示、重复停止被禁用、部分回复保留、输入与发送恢复；测试通过模拟桥接状态验证界面，不对真实网络取消延迟作保证。

思考区回归在 380 像素宽的聊天窗口实际点击展开、收起和复制，检查计时增长、纯文本原样复制、限高、流式展开状态保留、停止及历史内容可读、缺少内容时隐藏，以及四种阶段文案。协议回归使用真实下拉框键盘选择，核对保存命令、旧协议保留和服务范围。这些是合成响应的界面验证；DeepSeek 与 Responses 的实际服务验收由根代理另记。

短面板回归复现“聊天在播放器上方”的交换布局，实际拖动分隔条压缩聊天，并在 1042、720、600 像素高的窗口检查输入、发送、模型、思考强度完整可见，回复区与下方播放器仍有空间，最矮窗口实际点击发送成功。此轮扩充既有测试，最终仍为 **25 项通过（17.61 秒）**，Ruff 通过。首次合并执行在第三个工作区测试的对象初始化／垃圾回收阶段发生 Qt/PySide 原生访问异常，新增短面板用例尚未执行；未修改生产代码规避该异常，完整复跑通过。此异常记录保留，不将复跑通过描述为首次运行无异常。

隔离合成内容截图位于 `.cache/v5-ui/`，已目视检查 1280 像素与 980 像素宽的学习工作区，以及 380 像素宽的聊天窗口。

以上是源码应用的 QML 交互与布局证据，不等同于实际便携 EXE、真实视频解码、服务商账号或生成内容质量的完整验收。根代理进行的实际 EXE 验收另行记录；本轮 UI 测试没有操作用户正在使用的窗口，也没有使用个人学习数据。
