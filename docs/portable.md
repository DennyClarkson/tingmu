# 听幕便携版使用指南

[English](portable.en.md)

在 GitHub Releases 的附件中选择 Windows x64 便携 ZIP，将整个压缩包解压到有写入权限、空间足够的位置。打开解压出的 `Tingmu` 文件夹，双击 `Tingmu.exe`。同一目录中的 `LICENSE` 收录听幕的 Apache-2.0 许可证，`THIRD_PARTY_NOTICES.md` 列出第三方组件、来源及其各自的许可。[GitHub Releases](https://github.com/DennyClarkson/tingmu/releases)

随包提供 Qt Quick 播放器、四套完整字体、Python 和基础学习工具。视频解码使用 Qt 自带的多媒体插件。干净发行包首次启动时没有个人资料、模型连接或识别权重，默认工作区已停用文本 API。已有安装会恢复上次使用的工作区。

## 首次播放与准备

首次打开时，「运行环境与依赖管理」会在后台离线检查本机。点「暂不下载，直接进入」即可用 **0 B 下载**播放视频、使用外挂字幕。以后可从「文件」菜单或「工作区设置 → 语音识别」再次打开。显示「已复用本机组件 · 0 B」的项目可直接使用。

| 想使用的功能 | 一次性准备 |
| --- | --- |
| 打开视频、切换音轨、阅读外挂字幕或学习文档 | 随包就绪。 |
| 提取音轨、调用本机或外部转写 API、解码内嵌字幕 | 检测或指定同时包含 FFmpeg 和 FFprobe 的目录。缺少工具时可勾选安装到 `bin/`。 |
| 使用本地 Whisper 或 ONNX 语音处理 | 勾选本地 Whisper 引擎；使用 API 转写或外挂字幕时可跳过。 |
| 使用 NVIDIA 加速 Whisper | 检测现有 CUDA 12 / cuDNN 9 动态库。仅在具有兼容 NVIDIA 显卡且缺少可复用运行库时选择安装。 |
| 使用 Qwen3-ASR | 选择本机已装好 PyTorch 和 Qwen3-ASR 的 Python 环境，或明确勾选数 GiB 的独立运行环境。 |

界面会显示所选组件的预计下载量。确认安装后可查看进度或取消。运行环境与模型权重分别管理。本地识别引擎就绪后，在对应工作区选模型并确认下载权重。搬迁后，若原电脑上的路径失效，可重新检测、指定新路径或将所需组件装进便携目录。

1. 用顶部工作区选择器新建或打开学习工作区。「用哪种语言学」决定译文和讲解的语言，「想学哪种语言」对应片中所学的原声。两者可以相同，也支持自填语言代码。
2. 选「文件 → 打开视频…」开始播放。媒体库可以引用任意位置的视频。若希望将片源和随附字幕一并保存在工作区，点「复制视频到工作区…」。也可在「工作区设置 → 语言与文件」打开视频目录，把文件放进 `media/`。打开「自动准备放入 media 的视频」后，听幕会等待复制完成，并在所需资源可用时排队处理。
3. 切到「准备」，在「新任务流程」选择经典流程或字幕 Agent。处理多音轨影片时，在队列齿轮的「处理音轨（从 0 开始）」填写所学原声对应的音轨序号。勾选媒体库中的视频，点「加入处理队列」，再点「开始队列」。
4. 在「观看」播放并阅读学习伴侣。可从「视图 → 界面语言 / Language」选择简体中文、繁體中文或 English。界面语言按整份安装保存，学习语言在每个工作区单独选择。

### 选择字幕的三个入口

| 想做什么 | 操作 | 结果 |
| --- | --- | --- |
| 播放时看一份外挂字幕 | 打开视频，点「文件 → 导入播放字幕…」 | SRT、VTT、ASS 或 SSA 存入当前工作区的 `playback-subtitles/`，可独立显示。已有学习文档继续使用。 |
| 用指定原文直接学习 | 选择默认的「经典流程」，打开对应视频，点「文件 → 从字幕建立学习文档…」。已有学习文档时菜单显示「从字幕替换学习文档…」。 | 所选字幕作为学习原文。日常队列也能寻找匹配的外挂文件，找不到时识别所选音轨。停用文本模型时可以准备原文与本地分词。 |
| 判断现有字幕能复用多少 | 选择「字幕 Agent」。让视频正常入队即可自动检查。要指定外挂文件，先打开视频，再点队列的「为当前视频选字幕并入队…」或「文件 → 选择字幕并加入 Agent 队列…」。 | 自动检查匹配的外挂字幕与内嵌轨。手动选择时检查该外挂文件及片内字幕。新队列项记住入队时的流程。 |

### 字幕 Agent 如何处理

Agent 按所选音轨、可辨认的剧集编号、实际字幕语言和时间覆盖检查候选来源。在任务卡上查看采用了哪份字幕、原文及已有译文句数、处理阶段。展开「字幕检查详情」可看见选错集数、对白覆盖不足、只有图像轨等原因。

| 检查结果 | 原文 | 译文与讲解 |
| --- | --- | --- |
| 有可采用的学习语言字幕 | 直接使用字幕及其时间 | 生成逐句讲解和缺少的译文，由讲解模型另行对照原文核验新译稿。 |
| 原文和译文可按时间配对 | 直接使用原文 | 保留配对的已有译文，只为缺译的句子补译、核验。全部配对时只需生成讲解。 |
| 只有已知语言译文 | 识别所选原声，可复用同片、同音轨和对应范围的原始识别 | 时间重叠的译文可供复核、讲解参考，依据识别原文生成并核验译稿。 |
| 没有可用的文字对白 | 识别所选原声 | 根据取得的原文准备译稿与讲解。图像字幕可供播放，自动取字需要 OCR，当前流程未实现。 |

字幕 Agent 的完成条件包括逐句讲解。缺少可用讲解模型时，听幕保存已取得的字幕并提示配置。点任务卡的「配置逐句讲解模型…」，选好模型和工作区权限后点「重试」。已有经典学习文档也可以在伴侣或播放器的「字幕」页点「补全讲解与译稿」，沿用已保存的阶段结果。

## 配置识别和文本模型

**本机识别。** 在「工作区设置 → 语音识别」选择内置 Whisper 或 Qwen。按学习语言和设备选模型，点「下载所选模型」，核对包大小和本次预计下载量后确认。下载时显示已接收字节和速度。同一安装的工作区共用权重。已有完整的 CTranslate2 Whisper 模型可放入安装内的 `.cache/models/`，再点「选择已有的本机 Whisper 模型…」。设备可选 `auto`、`cpu` 或 `cuda`，GPU 识别需要兼容的 NVIDIA 驱动。单纯播放和直接读取字幕无需下载识别模型。

**人声和分句。** 可另行下载人声分离及换人检测模型。启用预处理但缺少分离模型时会用频谱方法减弱重复背景声。缺少换人检测模型时，沿用识别器分句。原始识别文本和声学时间随材料保存。模型按文本划分长句时，屏幕分段时间为推算值。疑难台词可对照原声，使用「纠正此句 → 复核并保存」留下修订。[本地语音处理](https://github.com/DennyClarkson/tingmu/blob/main/docs/local-speech.md)

在准备队列的齿轮中选择「新任务分句方式」。默认的「本地分句」按时码、停顿和标点处理。「模型智能分句」使用已获工作区文本授权的复核模型，未分配时使用讲解模型。模型按原始字词或字幕的索引分组，听幕计算时间，对校验失败的部分使用本地结果。已有配对译文的字幕保留原分段。

**转写服务。** 也可使用已启动的本机回环 API，或指定一个远程转写接口。选择「外部 API · 远程转写」时，填写服务地址、模型和字幕格式，并明确勾选「允许此工作区发送音轨」。生成字幕时，听幕将所选音轨分段发往该地址。视频播放、音轨提取及预处理在本机进行。[外部语音接口](https://github.com/DennyClarkson/tingmu/blob/main/docs/external-asr.md)

**文本服务。** 在「文件 → 全局文本模型…」保存连接，并为「全文复核」「批量讲解」「学习对话」分配模型。同一安装共享连接和任务分配。每个工作区在「文本模型与 API」选择停用、仅本机 API 或允许远程文本 API。授权远程讲解只开放文本处理，发送音轨须在语音设置中另行授权。[模型连接与权限](https://github.com/DennyClarkson/tingmu/blob/main/docs/providers.md)

### 队列进度与重试

「工作区设置 → 文本模型与 API」及队列齿轮中的「高并发请求 LLM」支持同时处理 1–16 批请求，默认 4 批，关闭后为 1 批。更改在下个视频开始或暂停后继续时生效。任务卡列出当前阶段、已完成句数和各批次的状态。

遇到缺句或字段错误时，听幕保存已经校验通过的句子，只重试有问题的部分。响应截断或编号混乱时会拆小批次。多次仍失败时，可用任务卡上的句序、时间码或服务错误定位。限流时可调低并发，按提示等待后点「重试」。鉴权、余额或模型访问错误需要先检查连接。

要主动重新生成，先暂停队列，勾选要处理的任务，再点「仅重做讲解」或「清除识别与讲解」。前者保留识别和已复核原文。确认框可选择是否重新排队。重置前的材料备份在当前工作区的 `material-backups/`。

## 观看、收藏与对话

- **播放器。** 时间轴旁的齿轮可切换播放音轨、音频输出设备。进入「字幕」勾选「显示学习字幕」和「显示〈已知语言〉译文」即可双语观看。内嵌轨、导入字幕也可独立开启。普通窗口与全屏都可以拖动字幕，图像字幕可单独移动、缩放，再点「恢复字幕位置」可复位。「样式」可预览并保存文字字体、底框、描边和位置。
- **全屏。** 按 F 进入全屏，空格暂停或继续，Esc 退出。齿轮中可调整控制栏自动隐藏时间或为下栏预留空间。伴侣浮层可调透明度、字号及显示内容，拖其右下角改变大小。「视图」菜单可打开浮动模块、独立聊天窗口或恢复默认布局。
- **导出。** 从「文件」导出原文字幕。所有句子的译文都已从来源采纳或经过模型核验后，「导出〈已知语言〉译稿…」可用。当前工作区的 `documents/` 中也会保存学习 JSON、原文 SRT 和完整的 `.translation.srt`。
- **收藏与笔记。** 在伴侣中点击词卡、收藏整句，或在全屏暂停时选择字幕文字。先在「学习 → 收藏」查看，整理后写入分语种的 Markdown 笔记，保留手写内容和出处。再次遇到档案中已整理的词，第一次点击提示状态，再次点击同一词卡将其重新收进待整理收藏。笔记内每条出处可跳回对应视频中的原句。
- **对话。** 在「对话」输入「我要学英语了」可用本地向导查找或新建工作区、检查设备和已安装模型。确认下载可在原对话回复「同意下载」或点击确认按钮。配置学习对话模型后可询问当前句、操作播放和队列、整理笔记或保存讲解偏好。编辑和重试会另建会话分支，沿用发起时的视频、语种、模型和思考强度。新偏好在后续生成时使用。
- **后台处理。** 「文件 → 收起到系统托盘」可让下载和队列继续运行。点击 Windows 通知区域图标恢复窗口，右键可设置关闭窗口时的行为，或选择「退出听幕」。

## 上手指南、下载与准备进度

从「帮助 → 快速上手与使用说明」打开指南。只看视频和外挂字幕可以直接打开文件。要生成双语精讲，先在全局文本模型中分配讲解角色，再在当前工作区明确授权。读取内嵌字幕还需要 FFmpeg。没有字幕时，可在工作区选择安装本地语音引擎和识别权重，或指定转写 API。指南中的按钮可直接打开对应页面。

模型和运行环境下载会显示当前阶段、已收字节、速度和预计剩余时间。文件长度尚不完整时，总量会标明为估算。点「后台下载」可继续使用主窗口，点击底部下载状态可回到详情。校验、解压和离线安装阶段仍可查看进度。

准备视图列出所选任务的缺项和修复入口。开始后可查看来源轨道、分句统计、并行批次及最近核验的双语句子。任务完成后可直接在放映室打开。已入队的任务保留入队时的权限约束，修改设置后如需扩大权限，请按就绪清单提示重新入队。

## 数据位置、备份与诊断

| 安装内的位置 | 内容 |
| --- | --- |
| `data/` | 默认工作区、全局模型连接、工作区目录。新建工作区位于 `data/workspaces/`。 |
| 每个工作区 | `media/` 存放复制或放入的视频，`documents/` 保存学习材料，`notebooks/` 保存笔记，`study.db` 保存收藏、聊天及播放记录，`exports/` 是默认导出位置。 |
| `.cache/` | 同一安装共用的识别权重、运行缓存和临时文件。 |
| `app/`、`runtime/python/` | 应用、组件版本和 SHA-256 清单、随包的核心 Python 与 Qt。 |
| `bin/`、`.cache/runtime-deps/`、`runtime/asr/` | 用户按需安装的媒体工具、Whisper/ONNX 和 CUDA 库、独立 Qwen 环境。 |
| `data/runtime-setup.json` | 首次引导状态和已验证的外部组件路径。 |

关闭听幕再备份或移动整个便携文件夹。启动时可重新定位安装内的媒体引用。迁移前的数据库和 JSON 原件保存在工作区的 `migration-backups/`，目标有冲突时会停止迁移。目录外引用的视频仍需从原路径访问。使用个人资料的副本会包含这些学习记录。供他人首次使用的副本应使用下方的干净构建流程。

**用新版 ZIP 升级。** 从托盘退出听幕并备份整个旧文件夹。将新版完整解压到新的可写目录，首次启动前把旧安装的 `data/` 复制到新版 `Tingmu/`。要复用已下载的模型和可选组件，再复制已有的 `.cache/`、`bin/` 和 `runtime/asr/`，保留新版自带的 `app/` 和 `runtime/python/`。启动新版，核对上次使用的工作区、收藏、笔记和视频播放，重新检测依赖。换电脑或 Windows 账号后，需要重新输入手工保存的 API 密钥。需要回退时，从备份打开旧版。

启动错误可在安装内的 `data/logs/application.log` 查看。在「帮助 → 开发者模式 → 查看日志」可查看运行状态或点「导出诊断」，输出到当前工作区的 `diagnostics/`。运行事件记录在工作区的 `logs/events.jsonl`，每份约 2 MiB，保留 3 份轮转备份。启动日志同样限制在约 2 MiB，保留 2 份备份。诊断保留异常类型、代码位置和已脱敏的环境信息，排除字幕、对话、笔记和请求正文。

## 维护者构建与验收

使用准备好的 Windows x64 Python 3.12 开发环境 `.venv/` 构建。两个入口采用相同的核心包内容；一种读取开发环境，另一种以既有便携目录的主 Python 为输入。构建只取程序和运行依赖，使用系统 .NET Framework 编译器生成启动器，输出清单记录 Qt 闭包、资源哈希与模型审计结果。[开发环境](https://github.com/DennyClarkson/tingmu/blob/main/docs/development.md)

在仓库根目录执行以下命令，使用新的 QA 目录。每次打包只需选一个构建入口。

```powershell
$qa = '.cache/qa/bundle-opt'
New-Item -ItemType Directory -Force $qa | Out-Null
.venv/Scripts/python.exe -B packaging/build_portable.py --destination "$qa/Tingmu"
# 从已有便携目录生成同一款干净发行包
.venv/Scripts/python.exe -B packaging/build_clean_install.py "$qa/clean" --source "$qa/Tingmu"
```

更新已有安装前先退出听幕和托盘进程。`packaging/build_clean_install.py <安装目录> --refresh` 更新程序及清单，保留工作区、模型和按需安装的组件。启动器源码或图标有变化时，在新目录完整构建。

在搬迁后的副本运行 `Tingmu.exe --portable-smoke --smoke-media "双音轨视频绝对路径"` 可离线验证播放、音轨切换、定位、倍速、暂停、字体和首次引导。有系统托盘时也会测试隐藏和恢复窗口。无显示器时可设置 `QT_QPA_PLATFORM=offscreen` 和 `QT_QUICK_BACKEND=software`。报告在副本的 `data/logs/portable-smoke.json`，测试工作区与引导状态保存在 `.cache/portable-smoke/`。[体积、冷启动与实测](https://github.com/DennyClarkson/tingmu/blob/main/docs/bundle-and-startup-optimization.md)
