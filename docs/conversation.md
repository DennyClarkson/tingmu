# 对话式学习伴侣

在主界面打开「对话」，可以问当前字幕里的某个表达、继续上次的练习，或请伴侣把所选视频加入处理队列。没有打开视频时也可以提问，或用「用中文学英语」这样的请求创建学习工作区。

## 模型与会话

在「文件 → 全局文本模型 → 任务分配」为学习伴侣选择连接。复核、讲解和对话可分别指定模型。工作区可以使用本机回环服务，使用远程连接前需允许远程文本。聊天中的思考强度取决于连接和模型支持的选项。公开返回的思考文本或摘要可单独展开，签名和私有推理数据不进入会话记录。[模型设置与凭据](providers.md)

每次请求保留发起时的会话、工作区语言、视频和选中字幕，以及模型和思考强度。切换视频后，原回复仍回到发起它的会话。停止后可以查看已经收到的回答。编辑与重试会另建分支，原会话可继续查看。

## 可以让伴侣做什么

| 请求示例 | 应用行为 |
| --- | --- |
| 「这句里的这个词是什么意思？」 | 结合当前字幕、工作区语言和有限的对话历史答疑。涉及实际发音时可跳回原声核对。 |
| 「把选中的视频用字幕 Agent 处理」 | 对所选视频创建或运行队列任务。可在「准备」查看字幕来源、步骤与结果。 |
| 「把我收藏的词整理成笔记」 | 将收藏及其视频出处整理进学习笔记。修改已有笔记时读取全文并检查修订号，保留手写内容。 |
| 「以后多解释口语里的省略」 | 将讲解偏好保存到工作区，随后生成材料时采用。要重做已有材料，可明确指定视频和范围。 |

应用只向伴侣开放列出的操作，执行结果回到原会话。字幕和聊天里的引文作为学习材料处理。发送给文本服务的上下文按字段筛选，如当前字幕、语言、媒体名称和播放状态。语音转写及发送音轨另由工作区设置控制。[准备流程](portable.md) · [语音服务权限](external-asr.md)
