Qt Windows software OpenGL renderer (opengl32sw.dll)
===================================================

Qt distributes Mesa's llvmpipe software rasterizer with the Windows
package. This build uses Mesa 11.2.2 and LLVM 3.6.2. Qt's build notes
describe its patched build with Visual Studio 2015 and the libgl-gdi
target. Tingmu redistributes the DLL supplied with PySide6.

Qt's build instructions for these versions:
https://wiki.qt.io/index.php?title=MesaLlvmpipe&oldid=28759

Mesa's component overview and the LLVM release license are provided in
../Mesa-11.2.2.html and ../LLVM-3.6.2.txt. The adjacent LLVM-regex.txt
contains the OpenBSD regular-expression notices from LLVM 3.6.2.
https://github.com/llvm/llvm-project/blob/llvmorg-3.6.2/llvm/lib/Support/COPYRIGHT.regex

Qt's published attributions for this Windows DLL:
https://doc.qt.io/qt-6.12/qt-attribution-llvmpipe.html

LLVM 3.6.2 MD5 implementation
-----------------------------

https://github.com/llvm/llvm-project/blob/llvmorg-3.6.2/llvm/lib/Support/MD5.cpp

(This is a heavily cut-down "BSD license".)

This differs from Colin Plumb's older public domain implementation in that
no exactly 32-bit integer data type is required (any 32-bit or wider
unsigned integer data type will do), there's no compile-time endianness
configuration, and the function prototypes match OpenSSL's.  No code from
Colin Plumb's implementation has been reused; this comment merely compares
the properties of the two independent implementations.

The primary goals of this implementation are portability and ease of use.
It is meant to be fast, but not as fast as possible.  Some known
optimizations are not included to reduce source code size and avoid
compile-time configuration.
